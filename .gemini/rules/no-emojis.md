# Diretiva Global: Proibição Estrita de Emojis

NUNCA use emojis em nenhum arquivo do projeto Helper Node (HTML, JavaScript, CSS, scripts, documentação, mensagens de log ou interface de usuário).

Diretrizes:
1. Todos os botões, títulos, status, badges, alertas e cards devem utilizar apenas texto claro e padronizado.
2. Quando um elemento gráfico for necessário (ex.: fechar, maximizar, engrenagem, terminal), utilize exclusivamente vetores SVG limpos inline.
3. Não insira caracteres Unicode do bloco de emojis em comentários, strings de interface ou layouts.
